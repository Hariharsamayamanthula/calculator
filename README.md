# Calculator

A simple, fast, and lightweight calculator supporting basic arithmetic operations:
- Addition (`+`)
- Subtraction (`-`)
- Multiplication (`*`)
- Division (`/`)

No bloat, no lag, zero external dependencies.

## Usage

### 1. Web Calculator (`index.html`)
Open `index.html` in any web browser.
- Click buttons or use your keyboard (numbers, `+`, `-`, `*`, `/`, `Enter`, `Backspace`, `Escape`).

### 2. Command Line Calculator (`calculator.py`)
Run interactively:
```bash
python3 calculator.py
```

Or pass arguments directly:
```bash
python3 calculator.py 15 * 4
```
